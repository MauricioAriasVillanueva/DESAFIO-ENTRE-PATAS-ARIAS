# Entre Patas – Arias · Registro

Versión individual para dar de alta un propietario junto con su mascota en una aplicación de consola.

## Funcionalidad conectada

La opción **1. Registrar propietario y mascota** solicita los datos de ambos registros, valida el teléfono de nueve dígitos y asigna códigos consecutivos. Al terminar muestra la información registrada. Las demás opciones visibles —buscar, modificar, eliminar, mostrar y ordenar— responden que todavía no están implementadas.

Los datos se conservan en listas durante la ejecución; esta rama no incluye almacenamiento en archivos.

## Archivos

```text
Program.cs
Registro_Propietarios_Mascotas.psc pseint
README.md
```

El archivo PSeInt conserva el nombre exacto con el que figura en esta rama. Hay código C# en `Program.cs`, pero no se incluye un archivo `.csproj`; para ejecutarlo con .NET es necesario incorporarlo a un proyecto de consola local.
